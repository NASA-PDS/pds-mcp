# Development and usage

This document covers installation, server execution, MCP client configuration,
research evaluation, and development workflows. For the study motivation and
results, see the [main README](README.md).

## Requirements

- Python 3.13+
- Access to the public NASA PDS Search API for live MCP queries

## Installation

```bash
git clone https://github.com/NASA-PDS/pds-mcp-server.git
cd pds-mcp-server
python3.13 -m venv .venv
source .venv/bin/activate
pip install -e '.[research]'
```

## Run the MCP server

After installing the package:

```bash
python -m pds_mcp_server
```

## MCP client configuration

Use the virtual environment's Python executable so that the installed package
and dependencies are available:

```json
{
  "mcpServers": {
    "pds-registry": {
      "command": "/absolute/path/to/pds-mcp-server/.venv/bin/python",
      "args": ["-m", "pds_mcp_server"]
    }
  }
}
```

Claude Desktop-specific notes are available in
[`Claude_Desktop.md`](Claude_Desktop.md).

## Research commands

Validate the final benchmark:

```bash
.venv/bin/pds-research validate research/data/main-300-live.jsonl
```

Recompute metrics for one of the committed prediction files:

```bash
.venv/bin/pds-research score \
  research/data/main-300-live.jsonl \
  research/results/codex-live-main-300-gpt-5.6-luna.jsonl
```

Run or resume the multistep live-MCP evaluator:

```bash
.venv/bin/pds-research codex-mcp-batch \
  research/data/main-300-live.jsonl \
  --output research/results/predictions.jsonl \
  --trajectories research/results/trajectories/run-name \
  --model gpt-5.6-luna \
  --workers 1
```

This command uses the local Codex login. Increase concurrency carefully because
each worker creates an independent model and MCP session.

## Tests

```bash
.venv/bin/pytest -q
```

## MCP Inspector

```bash
npx @modelcontextprotocol/inspector .venv/bin/python -m pds_mcp_server
```

## Example custom host

The [`src/gradio`](src/gradio) directory contains an earlier Gradio-based MCP
host using Hugging Face smolagents and the OpenAI SDK. It is retained as a
development example and is not part of the reported evaluation.

## Repository layout

```text
src/pds_mcp_server.py       Live FastMCP server
src/pds_research/           Benchmark and evaluation harness
research/data/              Final benchmark
research/results/           Predictions, metrics, tables, and figures
tests/                      Unit and artifact-integrity tests
```

Large per-question trajectories and API response caches are ignored by Git.
They are local audit artifacts and can be regenerated by rerunning the relevant
commands.
